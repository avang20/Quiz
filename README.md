
# QuizDuo — نسخه یکپارچه توسعه‌یافته

این پوشه شامل فایل‌های اصلی ارسالی و فایل‌های افزوده‌شده برای چالش روزانه، تسک‌ها، ارتباط اجتماعی و نمونه‌های بازی است.

## نصب روی GitHub Pages

1. تمام محتویات این پوشه را در ریشه مخزن GitHub Pages جایگزین/بارگذاری کن؛ مسیرها را تغییر نده.
2. مطمئن شو `index.html` در ریشه مخزن قرار دارد.
3. فایل‌های `data/general.json` و `data/fun.json` باید در پوشه `data` باشند.

## به‌روزرسانی Google Apps Script

1. وارد پروژه Apps Script متصل به QuizDuo شو.
2. محتوای `backend/Code.gs` را جایگزین فایل `Code.gs` کن.
3. محتوای `backend/Admin.html` را جایگزین فایل HTML با نام دقیق `Admin` کن.
4. پروژه را ذخیره کن و از مسیر Deploy → Manage deployments نسخه موجود Web App را ویرایش و نسخه جدید را منتشر کن. آدرس Web App موجود در `app.js` و `features.js` در این بسته حفظ شده است.
5. در اولین درخواست قابلیت‌های جدید، شیت `QuizDuoFeatures` به‌صورت خودکار ساخته می‌شود.

## مدیریت چالش روزانه

در پنل مدیریت، تب «چالش روز» اضافه شده است. مدیر می‌تواند سؤال و گزینه‌ها را وارد کند یا یکی از سؤال‌های بانک پیش‌فرض را انتخاب و برای امروز ثبت کند. اگر چالش دستی ثبت نشود، سرور از بانک پیش‌فرض یک سؤال تصادفی برای همان روز تعیین می‌کند.

## امکانات اضافه‌شده

- چالش روزانه با بانک اولیه چندموضوعی و پاداش XP
- تسک‌های روزانه با پاداش XP، قلب اضافه و ۳۰ دقیقه قلب نامحدود
- درخواست دوستی و پذیرش درخواست
- ساخت گروه، دعوت به گروه و ساخت تورنومنت گروهی
- صف اولیه حریف تصادفی و دعوت دوست برای شطرنج/تخته‌نرد/UNO
- نمونه محلی شطرنج و UNO با بات ساده

## محدودیت‌های مهم این نسخه

این بسته یکپارچه‌سازی اولیه است، نه نسخه نهایی رقابت آنلاین حرفه‌ای. در شطرنج فعلی، حرکت‌های پایه مهره‌ها بررسی می‌شود اما تمام قواعد رسمی (قلعه‌رفتن، آن‌پاسان، جلوگیری کامل از قرارگرفتن شاه در کیش، تشخیص قطعی کیش‌ومات) هنوز پیاده‌سازی نشده‌اند. تخته‌نرد فعلاً میز/نمونه اولیه است و موتور کامل قوانین و حرکت‌ها ندارد. UNO هم نسخه پایه محلی است. صف حریف تصادفی و دعوت دوست در سرور ثبت می‌شود، اما همگام‌سازی نوبت‌به‌نوبت بازی آنلاین و داوری سمت سرور هنوز کامل نیست.

همچنین سیستم ورود فعلی پروژه از ساختار localStorage قبلی استفاده می‌کند؛ بنابراین نام کاربری ارسالی به سرور در این نسخه هویت امن و احراز‌شده محسوب نمی‌شود. پیش از برگزاری مسابقات با جایزه واقعی، باید احراز هویت سمت سرور، ثبت و داوری حرکت‌ها، جلوگیری از تقلب و تأیید پاداش‌ها تکمیل شود.

## ساختار

- `index.html` — رابط اصلی
- `css/` — استایل اصلی و استایل قابلیت‌های جدید
- `data/` — بانک سؤال‌ها
- `js/core/` — منطق فعلی برنامه
- `js/extra/features.js` — قابلیت‌های جدید
- `js/offline/` و `js/online/` — ماژول‌های وضعیت اتصال
- `backend/` — کد Google Apps Script و پنل مدیریت
